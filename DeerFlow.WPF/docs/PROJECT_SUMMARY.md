## 🏗 架构设计

### 四层架构
```
┌─────────────────────────────────────────┐
│         应用层 (ViewModels/UI)          │
│  ChatViewModel / HomeViewModel         │
│  FeedbackControl / PatternGraphControl │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│         插件层 (SK Plugins)             │
│  SelfImprovementPlugin (8 工具函数)     │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│         服务层 (Services)               │
│  8 个核心服务 + DI 容器                  │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│         数据层 (Models/SQLite)          │
│  8 个数据模型 + 持久化存储               │
└─────────────────────────────────────────┘
```

### 核心服务 (8 个)
1. `ISelfReflectionService` - 自我反思
2. `IPatternMiner` - 模式挖掘
3. `IAutoEvolver` - 自动演化
4. `IExperienceMemoryStore` - 经验存储
5. `IFeedbackService` - 用户反馈
6. `IAlertService` - 智能告警
7. `IDocumentGenerationService` - 文档生成
8. `IPlugin` - SK 插件系统

### 设计模式应用
- **依赖注入**: 完整的 DI 容器集成
- **接口抽象**: 所有服务均定义接口
- **异步编程**: 全面使用 async/await
- **并发安全**: Concurrent 集合保护
- **观察者模式**: 事件驱动的通知机制
